## Hasil lokal

- Node.js 24.11.1; `npm ci --dry-run --ignore-scripts --no-audit --no-fund --offline` lulus setelah perbaikan lockfile.
- `npm run typecheck`, `npm run lint`, delapan tes `npm test`, dan `npm run build` lulus.
- Export memiliki 29 halaman konten, halaman 404, robots, dan sitemap. Verifier memeriksa 31 berkas HTML, 1.140 referensi tautan/aset, 17 rute utama/baru, enam gambar karya, tiga tier harga, structured data, serta origin canonical dan sitemap produksi.
- Chrome headless: enam rute pada empat viewport (1440, 820, 390, 320 px), total 24 kombinasi, tanpa horizontal overflow atau JavaScript page errors. Rute: beranda, pricelist, detail dashboard, detail sistem custom, indeks karya, dan detail Aruna Rent.
- Pencarian tidak peka kapital, filter kategori, empty state dan reset, pemilihan layanan, validasi form wajib, kebutuhan tambahan, preview, dan encoding nama Unicode/tanda baca pada tautan WhatsApp lulus.
- Brief membawa tier harga yang dipilih, menandai kebutuhan tambahan untuk dibahas, dan memakai penawaran sesuai scope untuk layanan custom. Mengganti layanan membatalkan preview lama.
- Detail menuju brief, query layanan langsung, fallback query tidak dikenal, filter karya, status demo, FAQ, navigasi HP, dan scroll tabel perbandingan yang terisolasi lulus.
- Screenshot desktop/HP ditinjau untuk beranda, kartu paket, pricelist, detail layanan, indeks karya, dan detail demo rental.

## Perbaikan dari pemeriksaan

Elemen screen-reader pada tabel perbandingan kini berada dalam containing block milik scroll region sehingga tidak membuat dokumen mobile melebar. Pada layar sampai 360 px, CTA header berpindah ke menu agar logo dan tombol navigasi tetap muat. Jarak hero dan visual di HP ditambah.

## Batas pemeriksaan

Viewport merupakan emulasi Chrome pada Windows, bukan perangkat fisik. Brief hanya diperiksa dan URL WhatsApp didekode; tidak ada pesan dikirim, transaksi, login ke dashboard pelanggan, perubahan produk, atau penulisan database produksi. Aruna Rent tetap demo lokal dengan data fiktif. Screenshot lima website aktif berasal dari halaman publik yang memberi HTTP 200 pada hari pemeriksaan.

Deployment mengikuti integrasi Vercel branch `prod`; status produksi diverifikasi terpisah sesudah push.

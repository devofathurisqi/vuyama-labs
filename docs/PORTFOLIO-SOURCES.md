## Harga dan kemampuan

- **Rp150.000:** README `link_euu_150`, `solaceore_150`, dan `eljab_id_150` di `C:\project-devo\dropshipper_catalog_vuyama` menyatakan paket katalog tanpa dashboard. Pencarian, filter, foto/varian, favorit, keranjang, dan draft WhatsApp terdokumentasi.
- **Rp250.000:** implementasi `rumea_250_1`, dengan halaman brand/panduan, arah editorial, katalog, detail, varian, tas, metadata, dan output halaman statis. Tanpa dashboard. Signature menyusun penawaran desain lebih personal dari pola implementasi ini; jumlah halaman/revisi tetap perlu kesepakatan.
- **Rp350.000:** `README-PAKET-DASHBOARD.md`, README Novola/Bunavé, `qa/upload-2026-11-05/RESULTS.md`, dan `qa/bunave-upload-2026-11-06/RESULTS.md` mendokumentasikan katalog + dashboard sekali bayar: login, kelola produk/kategori/foto/varian/harga/stok manual, draft, publikasi, duplikasi, aktivitas, dan optimasi upload. Tidak menjanjikan pembayaran atau pengurangan stok otomatis.
- **Sistem custom:** `C:\project-devo\vuyama-labs-rental-mobil\README.md` dan `VALIDATION.md` mendokumentasikan demo rental dengan autentikasi, database, kalender, pemeriksaan bentrok, invoice, pembayaran manual, deposit, maintenance, dan peran. Status tetap demo lokal.
- **AI, integrasi, website bisnis, dan 3D:** cakupan kemampuan berasal dari profil studio yang sudah ada serta implementasi `admin-bot-vuyama` dan `vuyama-immersive`. Harga tidak tersedia sehingga tetap berdasarkan proposal. Demo AI pada website profil tetap memakai skenario lokal.

Segmentasi paket menjelaskan arah desain dan cara pengelolaan. Harga merupakan harga mulai untuk pembuatan sesuai scope. Kuota produk, waktu, revisi, biaya API, dan paket hosting tidak direka. Materi supplier Vuyama bersifat opsional; layanan terbuka untuk produk dan identitas bisnis calon pelanggan sendiri.
